# 🏡 House Price Prediction - End-to-End ML Project

An end-to-end machine learning pipeline that predicts house prices based on various features like area, location, and furnishing status. 

## 🚀 Features
* **Machine Learning Model:** Random Forest Regressor trained on real estate data.
* **Backend API:** Built with FastAPI to handle data validation and serve predictions.
* **Frontend UI:** Interactive web application built with Streamlit.

## 🛠️ Tech Stack
* **Data Science:** Python, Pandas, Numpy, Scikit-Learn
* **Backend:** FastAPI, Uvicorn, Pydantic
* **Frontend:** Streamlit
